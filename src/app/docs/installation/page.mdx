# Installation

Get started by installing the necessary dependencies for your project.

## Prerequisites

Before you begin, make sure you have:

- Node.js 18.17 or later
- A package manager like npm, yarn, or pnpm

## Install Dependencies

Run the following command to install the required packages:
```bash
npm install tailwindcss
```

## Configuration

After installation, you'll need to configure your project. Create a configuration file and add the following:
```tsx
export default function App() {
  return <div>Hello World</div>;
}
```

## Next Steps

Now that you've installed everything, you can start building your components.
